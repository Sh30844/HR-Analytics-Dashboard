# HR Analytics Dashboard (Power BI)

## 📊 Project Overview
This Power BI dashboard provides insights into HR data including employee count, attrition rate, department distribution, and gender diversity.  
The goal was to visualize key HR metrics to help decision-makers understand workforce trends.

## 🧩 Steps Performed
- Imported HR dataset (CSV file) into Power BI
- Cleaned data (handled missing values, fixed data types, formatted columns)
- Created measures for total employees, attrition rate, and average age
- Built interactive visuals (bar charts, pie charts, KPIs, slicers)
- Designed a clean, professional dashboard layout

## 🛠️ Tools Used
- Power BI Desktop  
- CSV/Excel Dataset
